# Getting help

| You want to... | Go to |
|---|---|
| Give feedback, show your project, or chat with other developers and supporters | [Discord](https://discord.gg/CbaChQphmW) |
| Ask how something works, or get help with local setup | [Discussions → Q&A](https://github.com/Renanuya/buymeatokens-oss/discussions/categories/q-a) |
| Suggest a feature or vote on ideas | [Discussions → Ideas](https://github.com/Renanuya/buymeatokens-oss/discussions/categories/ideas) |
| Report a bug | [Open a bug report](https://github.com/Renanuya/buymeatokens-oss/issues/new?template=bug_report.yml) |
| Report a security problem | [SECURITY.md](SECURITY.md). Please don't post it publicly. |
| Get help with your creator account on buymeatokens.com | hello@buymeatokens.com |

Please search first; your question may already have an answer. Never post API keys, wallet keys, session cookies
or other people's personal data in an issue or discussion. If you do by accident, rotate the key right away and
let us know so we can delete the post.
